# PanTree

PanTree is an analysis and visualization toolkit for pangenomic VCF files (such as those generated by minigraph's `cactus-pangenome`). It partitions genomes into sliding genomic or fixed-variant windows to compute variant density, unique allele distributions, phylogenetic relationships, and pairwise distance statistics across lineages, and renders publication-ready chromosome-level visualizations.

---

## 1. Synopsis

PanTree operates in two primary workflows:
1. **Calculation (`pantree.py calculate`)**: Slices indexed VCFs into sliding windows by genomic base pairs or fixed variant counts. For each window, it tallies variant counts, per-sample called sites, unique alleles, and sequence base pairs, computes pairwise distance metrics (Patristic NJ tree distance, Jaccard distance, and normalized Manhattan distance), and constructs Neighbor-Joining phylogenetic trees.
2. **Visualization (`pantree.py visualize`)**: Ingests calculated TSV files to produce chromosome-wide scatter and LOESS smoothed trend plots for each distance metric (rendered in duplicate with variant count and basepair background densities) as well as variant occupancy and unique variant proportion profiles.

---

## 2. Installation

PanTree requires Python 3.8+ and standard scientific bioinformatics libraries.

### Prerequisites & Dependencies

Install required Python packages:

```bash
pip install pysam biopython scipy numpy pandas statsmodels matplotlib
```

Input VCF files must be bgzipped and tabix-indexed (`.vcf.gz` and `.vcf.gz.tbi`). If starting with an uncompressed VCF:

```bash
bgzip -c input.vcf > input.vcf.gz
tabix -p vcf input.vcf.gz
```

## 3. Core Commands

PanTree provides two main subroutines via `pantree.py`:

```bash
python3 pantree.py [calculate | visualize] [options]
```

### `calculate`

Computes window metrics, distances, and Neighbor-Joining trees across the genome.

```bash
python3 pantree.py calculate \
    -i input.vcf.gz \
    -o results.tsv \
    -w 50000 \
    -l 10000 \
    -t 4 \
    -v
```

#### Arguments
* `-i`, `--input`: Input VCF or VCF.gz (tabix-indexed, required).
* `-o`, `--output`: Destination TSV output file (required).
* `-s`, `--samples`: Comma-separated list of sample names to include (default: all samples in VCF).
* `-w`, `--window-size`: Window size in base pairs (or variant count if `-f` is used; default: `10000`).
* `-l`, `--overlap`: Window overlap in base pairs or variant count (default: `0`, meaning non-overlapping adjacent windows).
* `-f`, `--fixed-variants`: Construct windows using a fixed number of variants rather than genomic base pairs.
* `-r`, `--include-ref`: Incorporate the reference genome (`REF`) into unique allele counts, alignments, and tree building.
* `-t`, `--threads`: Number of parallel worker threads/processes (default: `1`).
* `-v`, `--verbose`: Enable verbose step reporting.

#### Tabulated Metrics
* **Window Summary**: `Chromosome`, `Window_start`, `Window_end`, `Total_variants`, `Total_SNPs`, `Total_MNPs`, `Total_INDELs`, `Total_bp`, and `Tree_newick`.
* **Per-Sample Metrics**:
  * `{sample}_called_sites`: Total non-missing called variant sites in the window.
  * `{sample}_snps`: Total called SNP sites in the window.
  * `{sample}_mnps`: Total called MNP sites in the window.
  * `{sample}_indels`: Total called INDEL sites in the window.
  * `{sample}_bp`: Total ungapped sequence length for the sample across the window.
  * `{sample}_unique_alleles`: Count of variants where the sample carries an allele unique among all evaluated samples.
* **Pairwise Metrics**:
  * `{s1}-{s2}_patristic`: Tip-to-tip phylogenetic distance derived from the window's Neighbor-Joining tree.
  * `{s1}-{s2}_jaccard`: Jaccard distance ($1 - \frac{\text{intersection}}{\text{union}}$) based on the presence of non-reference (ALT) alleles. (When `-r` is enabled, Jaccard distance is set to `NA` for comparisons involving `REF`).
  * `{s1}-{s2}_manhattan`: Manhattan distance normalized by the number of shared valid (non-missing) sites.

### `visualize`

Generates distance and variant distribution plots from the TSV produced by `calculate`.

```bash
python3 pantree.py visualize \
    -i results.tsv \
    -o plots/ \
    -s SampleA,SampleB,SampleC \
    -f 0.1 \
    --format png \
    -v
```

#### Arguments
* `-i`, `--input`: Input TSV generated by `pantree.py calculate` (required).
* `-o`, `--output-dir`: Output directory for generated figures (default: `plots`).
* `-s`, `--samples`: Comma-separated sample pool. Plots only pairs where **both** samples are in this pool.
* `-S`, `--focus-samples`: Comma-separated focus samples. Plots only pairs containing **at least one** of these samples.
* `-f`, `--frac`: LOESS smoothing fraction (between `0.0` and `1.0`; default: `0.1`).
* `--format`: Output image format: `png`, `pdf`, or `svg` (default: `png`).
* `-v`, `--verbose`: Enable verbose logging.

#### Generated Plots (per Chromosome)
1. **Distance Plots (in Duplicate)**:
   * **`{chrom}_{metric}_density_variants.{format}`**: Pairwise distance scatter and LOESS curves plotted over background `Total_variants` density.
   * **`{chrom}_{metric}_density_bp.{format}`**: Pairwise distance scatter and LOESS curves plotted over background `Total_bp` density.
   * Metrics generated: `patristic`, `jaccard`, and `manhattan`.
2. **Variant Proportion Plots**:
   * **`{chrom}_variant_occupancy.{format}`**: Sample variant occupancy (`{sample}_called_sites / Total_variants`) over `Total_variants` background density.
   * **`{chrom}_unique_variants_proportion.{format}`**: Proportion of unique alleles (`{sample}_unique_alleles / Total_variants`) over `Total_variants` background density.

## 4. Utils

Standalone and legacy utilities are preserved in `archive/utils/`:

* **`archive/utils/vcf_dist.py`**:
  Standalone script for computing windowed Neighbor-Joining trees and pairwise distance tables (Patristic, Jaccard, Manhattan) directly from VCF files using `pysam` and `Bio.Phylo`.
* **`archive/utils/vcf_vis.py`**:
  Standalone plotting script for visualizing window distances with background variant density tracks and LOESS smoothing.
* **`archive/utils/kmerWindowsPrepare.py`**:
  Utility script to chunk fasta sequences or reference assemblies into k-mer windows for downstream analysis.
