# PanTree

PanTree is a tool for analyzing pangenomic VCF files, specifically those generated by tools like `minigraph`'s `cactus-pangenome`. It provides a suite of analysis tools to investigate relatedness and introgression between lineages within a pangenome.

## Features

- **Phylogenetic Tree Construction**: Generate windowed trees (Neighbor-Joining or UPGMA) across pangenomic variants.
- **Multiple Metrics**: Beyond tree distances, PanTree supports:
    - Pairwise Identity (p-distance)
    - Jaccard Distance (based on shared non-reference alleles)
    - D-statistic (ABBA-BABA test) for introgression.
- **Variant Identity Heatmaps**: Visualize variant identity across windows and samples.
- **Nearest Neighbor Analysis**: Identify polarizing alleles and track their presence across samples.

## Installation

PanTree requires Python 3 and several dependencies:

```bash
pip install pandas biopython
```

## Usage

The main entry point is `PanTree/pantree.py`.

### 1. `trees` - Construct and Analyze Trees/Distances

```bash
python3 PanTree/pantree.py trees -i input.vcf -o output.tsv -w 10000 --metric tree --method nj
```

**Key Arguments:**
- `-i`, `--input`: Input VCF file (can be gzipped).
- `-o`, `--output`: Output TSV file.
- `-w`, `--window-size`: Window size in number of VCF records.
- `--metric`: Distance metric to use (`tree`, `p-distance`, `jaccard`, `d-stat`).
- `--method`: Tree construction method (`nj`, `upgma`).
- `-d`, `--distance`: Comma-separated list of samples for pairwise distances (or `All`).
- `--quadruple`: Four samples (P1, P2, P3, O) for the D-statistic.

### 2. `heatmap` - Generate Variant Identity Heatmap Data

```bash
python3 PanTree/pantree.py heatmap -i input.vcf -o output_prefix -w 10000
```

### 3. `nearest` - Polarize Alleles

```bash
python3 PanTree/pantree.py nearest -i input.vcf -t Sample1,Sample2 -w 10000
```

Identifies sites where target samples have distinct alleles and reports how often other samples match these target alleles in each window.

## Metrics Explanation

- **Tree Distance**: Normalized distance between samples in a Neighbor-Joining or UPGMA tree.
- **p-distance**: Raw genetic distance (1 - identity).
- **Jaccard Distance**: 1 - (Intersection/Union) of non-reference alleles. Useful for focusing on shared derived variants.
- **D-statistic**: ABBA-BABA test. A positive value indicates introgression between P2 and P3, while a negative value indicates introgression between P1 and P3.
